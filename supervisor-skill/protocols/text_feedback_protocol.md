# Text Feedback Protocol

Use this protocol when the user brings text into a supervision context.

## First diagnose

Before revising, identify:

- the text's job;
- the claim;
- the evidence or material relation;
- the reader problem;
- citation or attribution boundaries;
- relation to the larger project.

## Default response

Give feedback first. Rewrite only when the user asks.

Useful feedback shape:

1. What the paragraph is currently doing.
2. Where the claim or function is unclear.
3. What decision would improve it.
4. A possible revision only if requested.

## Do not

- smooth the text into generic academic prose;
- replace the user's judgement with a polished but different argument;
- fix style before diagnosing claim and function;
- treat a paragraph as project memory unless the user asks to preserve its consequence.
