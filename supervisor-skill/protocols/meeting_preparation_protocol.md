# Meeting Preparation Protocol

Use this protocol when the user is preparing for a supervisor, committee, collaborator, or advisory meeting.

## Read

Start with:

- `memory/project_map.yaml`
- `memory/current_focus.yaml`
- `memory/current_week.yaml` when timing matters
- latest session log only when continuity matters

Read topical logs only for issues that must appear in the meeting.

## Output options

Depending on the request, produce:

- short agenda;
- update script;
- questions to ask;
- decisions needed;
- risks to surface;
- post-meeting note template.

## Meeting prep is not automatically a session

Do not create a supervision-session log for meeting preparation unless the user explicitly frames the preparation as a session or asks to preserve the meeting outcome.
