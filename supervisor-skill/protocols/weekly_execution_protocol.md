# Weekly Execution Protocol

Use this protocol for weekly review, planning, carry-forward, blockers, and short execution checks.

## Read

Read:

- `memory/project_map.yaml`
- `memory/current_focus.yaml`
- `memory/current_week.yaml`

Also read `session_index.yaml` or topical logs only when the weekly question depends on them.

## Review output

Use this structure:

- Completed
- Unfinished or blocked
- Capacity or pattern
- Carry forward
- Next week candidates

Keep confirmed work separate from inferred work.

## Planning rules

- Do not invent progress.
- Carry forward only unfinished, blocked, waiting, or still-relevant items.
- Do not keep old completed items in the live week.
- Separate intellectual decisions from executable tasks.
- Add review points for uncertain work.
- Keep the plan small enough to be used.

## Memory update

Update `current_week.yaml` only when the user asks for memory edits or when the task is explicitly a weekly memory update.
