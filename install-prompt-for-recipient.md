```text
I want to set up supervisor-skill for my own research project.

Please read the skill and the memory folder skeleton. Help me initialize project_map.yaml and current_focus.yaml.

Important:
- do not use another person's project details;
- do not invent missing details;
- use unknown, provisional, or to_confirm where needed;
- ask only the minimum setup questions first;
- show proposed memory content before writing;
- do not create a supervision session log unless I explicitly say this is a supervision session.
```

If Codex asks where memory lives, answer with the path to your own research workspace's `memory/` folder.
