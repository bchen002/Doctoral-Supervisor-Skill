# Memory template

Copy this folder into the recipient's research workspace and rename it to `memory/`.

The files are intentionally sparse. Fill them with the recipient's own project information only.

Recommended first files:

- `project_map.yaml`
- `current_focus.yaml`
- `session_index.yaml`
- `log_index.yaml`

Use `current_week.yaml` only if the recipient wants weekly execution tracking.

Use `sessions/`, `logs/`, and `articles/` as the project grows.
